# Пульс активности — источник фитнес-ленты

Файл `fitness-feed.json` содержит 30 русскоязычных учебных публикаций о физической активности и 60 комментариев. Авторы комментариев вымышлены; это демонстрационные данные.

Формат: `schemaVersion: 1`, `posts: [{id,title,body}]`, `comments: {"<postId>": [{id,name,body}]}`. Не меняйте идентификаторы существующих публикаций: они используются избранным и ссылками приложения.

Приложение загружает файл из ветки `main` через raw.githubusercontent.com, хранит проверенную копию в SQLite и использует локальный снимок без сети. После изменения данных нажмите «Обновить» в ленте; GitHub может ненадолго кешировать raw-файл.

Здесь нет персональных тренировок, PIN, паролей, журналов пользователя или ключей подписи приложения.
